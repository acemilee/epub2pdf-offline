### 0.3 不能"直接当成品施工"的点

1. **字体类型不在本计划控制范围**：字体类型由 EPUB 的 CSS `font-family` 决定；本项目只提供 Windows 回退栈与系统字体补嵌（见 §2.5）。本计划只调"字号/行距/页边距"，不改字体族。
2. **绝对单位字号无法缩放**：EPUB CSS 若用 `px`/`pt` 写死字号，不会随根字号缩放（em/百分比会）。验收只覆盖"EPUB 相对字号 + 无字号"两类。
3. **`testbook/epub` 四本书没有 true PDF**：只能做主观"原生感"验收 + 客观比例/边距/字号断言，不能做逐页对标；`testbook/` 里旧 true PDF 只用于验证"封面比例可信度"，不作为排版对标。
4. **auto 默认会改变所有现有用户的输出纸张尺寸**（A4 → 封面比例）。这是用户明确要求的行为变更，必须在 RELEASE_NOTES 标注 breaking。
5. **页眉/页脚/页码**不在本次范围（Chromium 不支持 `@page` margin box，需 PDF 后处理，另立项）。

## 1. 目标与非目标

### 1.1 目标

| 编号 | 目标 | 可验收标准 |
| --- | --- | --- |
| G1 | **默认纸张 auto**：页面宽高比 = 封面宽高比，页高基准 9.25in | 有封面书页面比例与封面误差 < 1%；封面满版白边 < 2pt |
| G2 | **排版度量随页宽缩放**：页边距、字号、行距、段距、标题比例 | 正文行宽约 40 个全角字符（西文约 80 half-width），字号 clamp 9–13pt |
| G3 | **GUI 手动开始**：拖入只入队，点「开始转换」才转换；新增纸张/字号下拉 | 拖入后不调用转换；点开始后按所选参数运行；重启保留选项 |
| G4 | **CLI 参数化 + 打包回归** | `--page-size/--page-height/--font-scale` 生效；exe CLI/GUI smoke 通过 |
| G5 | **修复上一轮报告的 P0 兼容性问题**（JS 书整本失败、TOC `.html/.xhtml` 导致目录缺失） | 原始 JS EPUB 可直接转换；其生成目录页存在 |

### 1.2 非目标

- 不追求与任何"印刷版 PDF"逐页一致；不清洗 EPUB 的字体族/颜色/装饰。
- 不做固定版式（rendition/viewport）EPUB 的版式还原。
- 不做 GUI 预览、不做页眉页脚、不做进度条平滑动画。
- 不改 NCX 书签与字体嵌入逻辑。

### 2.5 字体归因（回答"字体类型是谁决定的"）

- **字体类型由 EPUB 的 CSS `font-family` 决定**；本项目只提供回退栈 `src/epub2pdf/core/normalizer.py:66-69`（Segoe UI / 微软雅黑 / PingFang / Noto Sans…），并在 EPUB 引用 webfont 时加载、缺字体时用系统字体子集补嵌（`font_embed.py`）。
- 因此"字体看起来不对"通常= EPUB 未带字体且指定了 Windows 未安装的字体族 → 回退到上述栈；这不是本轮要改的内容，规划里只做"字号/行距/页边距"的缩放。

### 2.6 封面比例数据（auto 的可行性证据）

| 书 | 封面像素 | 比例 |
| --- | --- | --- |
| AI Agents in Action | 790×990 | 0.7980（true PDF 页面 0.7973，误差 0.09%） |
| Learning JS Design Patterns | 1200×1574 | 0.7624（true PDF 页面 0.7619，误差 0.07%） |
| testbook/epub/Advances in Financial ML | 532×800 | 0.6650 |
| testbook/epub/Spec-Driven AI Engineering | 1086×1448 | 0.7500 |

结论：封面比例可作为页面比例依据；**绝对尺寸无法从 EPUB 得到**（隐含 DPI 不一致），因此页高取基准值。

## 3. 决策与默认值（用户已授权按默认执行）

| 编号 | 决策 | 默认 |
| --- | --- | --- |
| Q1 | auto 是否默认 | **是**。CLI 与 GUI 默认 `auto`；显式 `A4` 保留 |
| Q2 | 页高基准 | **9.25in = 666pt**；`--page-height` 可覆盖（6–14in，越界报错） |
| Q3 | 封面比例可信区间 | **0.58 ≤ r ≤ 0.86**；越界/无封面/解析失败 → **回退 A4 + WARNING** |
| Q4 | 字号公式 | auto 模式：`font = clamp(text_width / 40, 9pt, 13pt)`；再乘字号档位系数。A4 模式保持 **11pt**（v1.1.1 兼容） |
| Q5 | 行距 | auto 模式：语言为 `zh/ja/ko` → **1.55**，其余 → **1.40**；A4 模式保持 1.5 |
| Q6 | 页边距 | auto：左右 = 11.5%·W，上 = 8%·H，下 = 9%·H，最小 36pt；A4：保持 18/16/20/16mm |
| Q7 | 字号档位 | `auto`（不额外缩放）/`compact`×0.92/`normal`×1.0/`loose`×1.10 |
| Q8 | GUI 选项生效时机 | 点「开始转换」时，用当前下拉值为队列内所有待转任务生成参数；运行中下拉禁用 |
| Q9 | 封面填充 | auto：`object-fit:cover`（比例匹配，满版）；A4：保留 `contain` |
| Q10 | 上一轮 P0 兼容性修复是否纳入 | **纳入**（M1）；若用户后续明确排除，仅删除 M1 不影响其余任务 |

### M2 auto 开本 + 排版度量（2.5 人日）

#### T2.1 `layout.py`：纯函数排版计算

红测试（`tests/test_layout.py`）：

1. `test_auto_page_from_cover_790x990`：`compute_layout(cover=(790,990), page_height_pt=666)` → `width_pt≈531.4`、`height_pt=666`。
2. `test_auto_falls_back_to_a4_without_cover`、`test_auto_falls_back_when_ratio_out_of_range`（r=0.95 → A4 + `warning=True`）。
3. `test_font_size_clamped`：极窄/极宽页面 → `9 ≤ font ≤ 13`。
4. `test_cjk_line_height` / `test_latin_line_height`。
5. `test_image_dimensions_png_jpeg_gif_webp_svg`（内联最小字节样本，不引入 Pillow）。
6. `test_preset_sizes`（`6x9`、`7x10`、`B5`、`Letter`、`A4`、`WxH` 解析，非法值报 `ValueError`）。

实现要点：

- `@dataclass(frozen=True) Layout`：`page_width_pt/page_height_pt/margin_left_pt/margin_right_pt/margin_top_pt/margin_bottom_pt/font_size_pt/line_height/heading_scale/body_font_size_pt/toc_scale/cover_fill/warning/source`。
- 常量：`A4=(595.28,841.89)`、`PT_PER_IN=72`、`DEFAULT_PAGE_HEIGHT_PT=666`、`MIN_FONT=9`、`MAX_FONT=13`。
- 公式（auto）：`W=H*r`；左右 11.5%W；上下 8%/9%H；`text_width=W-左右`；`font=clamp(text_width/40,9,13)*font_scale`；`line_height=1.55 if lang in (zh,ja,ko) else 1.40`；`toc_scale=font/11`。
- 封面尺寸解析：PNG（IHDR）、JPEG（SOF0/2）、GIF（头）、WebP（VP8/VP8L/VP8X）、SVG（width/height 或 viewBox），失败返回 `None`。
- **不引入 Pillow**（保持运行时依赖不变）。

#### T2.2 normalizer 参数化

红测试（`tests/test_normalizer.py`）：

1. `test_print_css_uses_layout_page_size`：`normalize(book, tmp, layout=Layout(...400×600))` 生成的 `index.html` 含 `@page { size: 400pt 600pt;` 与对应 margin。
