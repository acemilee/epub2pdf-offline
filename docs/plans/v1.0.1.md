### 3.4 E2E 辅助与断言矩阵

`tests/e2e/conftest.py`：

```python
def convert_epub(epub_path, tmp_path) -> Path:   # 调 epub2pdf.cli.convert(quiet=True, timeout=120)
def pdf_doc(pdf_path) -> fitz.Document           # PyMuPDF
def underline_count(page) -> int                 # get_drawings() 中水平短线/扁矩形计数
def outline_entries(doc) -> list[tuple[int,str,int]]

def assert_type0_fonts_embedded(pdf_path)        # 每个 Type0 都有 FontFile/FontFile2/FontFile3
```

| 断言 | 对象 | 判定 |
| --- | --- | --- |
| `doc.page_count >= 章节数` | final.pdf | 失败=渲染丢页 |
| `len(outline) >= 章节数 - nav 页` 且每条 `page>=1` | final.pdf | 失败=书签缺失（D1 回归） |
| 所有 outline 标题不含 `EPBPFANCHOR` | final.pdf | 失败=锚点污染标题（T2.3 回归） |
| `outline_depth >= 2` | cjk final.pdf | 失败=多级书签丢失（T2.8） |
| 抽样 ≥10 条 outline：目标页文本包含标题 | final.pdf | 失败=书签页码错位（封面偏移/导入错误） |
| basic.pdf 图片页 `len(page.get_images()) >= 1` | final.pdf | 失败=CDP 路线丢图（T2.2 回归） |
